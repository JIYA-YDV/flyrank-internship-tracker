## 📖 What This Repo Is

A visual system — locked once, inherited everywhere.

This repo holds two connected FlyRank deliverables:

- **Week 2 — Identity Kit** — the fonts, palette, and logo my portfolio and every future asset inherit
- **Week 3 — Curated Image Set** — the real screenshots, portrait, and brand assets my portfolio ships with

Both were built so that any new page, case study, or share card I produce next stays visually consistent without re-deciding the small things.

##  The Rejection Note 🚫

> **Rejected:** an AI-generated cinematic "MindfulAI" dashboard mockup — glowing 3D emotion bars, fake user profile, holographic brain visualization. Genuinely beautiful.
>
> **Why I killed it:**
> 1. It looked *better* than my real Streamlit demo — the exact problem
> 2. Different product name, different features, different user — a lie by omission
> 3. Impossible to reproduce with my actual tech stack
>
> **Rule locked in:** *the image must never outpace the product.*

The rejected image is preserved in `/assets/images/rejected/` as literal proof of the choice.
