## 💛 Capstone Highlight

### Postpartum AI Companion
A warm, empathetic 24/7 AI health assistant supporting new mothers through postpartum recovery — built with Python, Groq (Llama 3.3 70B), and Gradio. Deployed live on Hugging Face Spaces.

**Key Features:**
- Empathetic, judgment-free responses
- Crisis detection with hotline referral
- Streaming conversations with memory
- Custom dark theme with pink branding
- Safety-first medical disclaimers

👉 [Try it live](https://huggingface.co/spaces/YDVJIYA/postpartum_AI_companion) · [Read the docs](./Capstone/General%20AI%20Fluency%20Impact%20Project/README.md) · [View AI Stack](./Capstone/General%20AI%20Fluency%20Impact%20Project/ai-stack.md)
