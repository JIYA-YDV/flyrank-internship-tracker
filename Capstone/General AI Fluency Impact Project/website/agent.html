🚀 Try It Yourself (Local Setup)

The agent runs locally with Python. Follow these steps to try it on your machine:

Clone the repository

Grab the source code from GitHub

git clone https://github.com/JIYA-YDV/flyrank-internship-tracker.git cd flyrank-internship-tracker

Navigate to agent folder

cd "Capstone/General AI Fluency Impact Project/agent"

Create virtual environment & install dependencies

python -m venv venv .\venv\Scripts\Activate.ps1 pip install -r requirements.txt

Get a FREE Groq API key

Sign up at console.groq.com — no credit card needed. Create a key and copy it.

Create .env file with your key

# In agent/ folder, create .env: GROQ_API_KEY=gsk_your_key_here

Run the agent

chainlit run app.py -w

Opens at http://localhost:8000 — start chatting! 💛
