🚀 Run Locally (Optional)

Want to run the agent on your own machine? Follow these steps:

Clone the repository

git clone https://github.com/JIYA-YDV/flyrank-internship-tracker.git cd flyrank-internship-tracker

Navigate to agent folder

cd "Capstone/General AI Fluency Impact Project/agent"

Setup environment & install dependencies

python -m venv venv .\venv\Scripts\Activate.ps1 pip install -r requirements.txt

Get a FREE Groq API key

Sign up at console.groq.com — no credit card needed.

Create .env file with your key

# Create agent/.env with: GROQ_API_KEY=gsk_your_key_here

Run the app

python app.py

Opens at http://localhost:7860 — start chatting! 💛
